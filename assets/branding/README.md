# LibraTray branding assets

`libratray-icon.png` is the 1024 px transparent master image.
`libratray.ico` contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 px frames
for the executable, windows, tray surface, Start menu shortcut, and installer.

The mark combines a compact monitor-light silhouette with two independently
controlled light channels: warm amber/ivory for the main light and teal for the
ambient light. The dark navy tile keeps the glyph legible in both light and
dark Windows surfaces and at tray size. It intentionally contains no Yeelight,
Xiaomi, or Mi Home logo or word mark.

The original raster concept was generated for this project with OpenAI's
built-in image-generation model, then locally chroma-keyed, cropped, resized,
and encoded into a multi-resolution Windows icon. The final PNG and ICO are
project assets distributed under LibraTray's Apache-2.0 license.
