# LibraTray v1.0.1

LibraTray v1.0.1 是面向 Yeelight Libra Pro（`lamp15` / YLTD003）的小型界面与控制更新。

[English release notes](https://github.com/tHank-CS/LibraTray/blob/v1.0.1/docs/releases/v1.0.1.md)

## 修复

- 移除不需要的系统标题栏，并保留相应窗口的关闭、拖动、缩放、最大化与还原操作。
- 修复主灯和氛围灯滑块开关变形、溢出的问题。
- 将氛围灯预设色块与外部圆角矩形边框统一。

## 更改

- 为自定义氛围灯颜色加入交互式调色盘。
- 滑块默认吸附步进调整为主灯亮度 5%、氛围灯亮度 20%、色温 100 K。
- 主灯色温默认控制范围为 3000–6400 K；可在设置中开启 Yeelight 已确认原生支持的
  2700–6500 K 范围。
- 支持范围限定为精确匹配的 `lamp15` / Yeelight Libra Pro / YLTD003。

本版本仍未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者警告。
