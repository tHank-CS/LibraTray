# LibraTray v1.0.0

LibraTray v1.0.0 is the first stable release of the tray-first, local-only
Windows controller for Yeelight Libra Pro (YLTD003).

[简体中文发布说明](https://github.com/tHank-CS/LibraTray/blob/v1.0.0/docs/releases/v1.0.0.zh-CN.md)

## Highlights

- Independent main-light and ambient-light power and brightness control.
- Main-light colour temperature from 3000 K to 6500 K.
- Whole-background RGB colours and up to 20 local dual-channel presets.
- Live reconciliation of application commands, device notifications, queries,
  and physical-controller changes.
- Bounded retries, request pacing, reconnect recovery, and cold-start ambient
  renderer recovery for the observed firmware-38 behavior.
- Configurable global shortcuts, tray-wheel brightness adjustment, and optional
  on-screen feedback.
- Opt-in Windows lock/display automation, current-user startup, and guarded
  shutdown/startup state restoration.
- Light, dark, and Windows-following themes with Simplified Chinese and English.
- Versioned local configuration import/export and redacted diagnostics.
- Self-contained Windows x64 portable ZIP and a current-user MSI installer.

## Install or update

Choose one official asset from this GitHub Release:

- `LibraTray-1.0.0-win-x64.msi` for the guided current-user installation;
- `LibraTray-1.0.0-win-x64.zip` for a portable self-contained copy;
- `SHA256SUMS.txt` to verify both downloads.

The MSI defaults to `%LOCALAPPDATA%\Programs\LibraTray` and allows another
current-user-writable destination. Existing release-candidate builds with the
same version number should be uninstalled before installing the final package.
Configuration is stored in the current Windows user profile.

## Requirements

- Windows 10 21H2 (build 19044) or later, or Windows 11;
- x64 processor;
- the PC and light on the same trusted LAN;
- Yeelight LAN control enabled where the vendor app and firmware expose it.

## Known limitations

- The binaries are not code-signed. Windows can display SmartScreen or
  unknown-publisher warnings; verify the SHA-256 manifest before running them.
- Only exact `lamp15` devices are controlled. Hardware validation for this
  release primarily used YLTD003 firmware 38.
- Two-zone background RGB is intentionally disabled. Immediate hardware tests
  succeeded, but its relationship to a later cold-start failure was not safely
  isolated.
- Firmware 38 can report an incorrect background-power notification after an
  independent background-off action. LibraTray resolves this with a state query.
- The observed firmware-38 ambient renderer can become silent after a cold power
  cycle. LibraTray performs one bounded scene refresh per reconnect epoch and
  restores the previously confirmed appearance when recovery is required.
- LibraTray uses Yeelight's plaintext local protocol. Use it only on a trusted
  private network; it does not provide transport authentication or encryption.

## Validation

The release candidate passed 304 automated tests, locked dependency restore,
Release compilation with analyzers, NuGet vulnerability audit, Windows CI
packaging, and maintainer testing of the application, real-device controls,
installation, uninstall, tray interaction, shortcuts, and Windows automation.
Code signing and a separate clean-VM pass are not claimed.
