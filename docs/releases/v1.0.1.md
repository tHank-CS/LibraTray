# LibraTray v1.0.1

LibraTray v1.0.1 is a small interface and control update for Yeelight Libra Pro
(`lamp15` / YLTD003).

[简体中文发布说明](https://github.com/tHank-CS/LibraTray/blob/v1.0.1/docs/releases/v1.0.1.zh-CN.md)

## Fixed

- Removed unwanted native title bars and retained close, drag, resize,
  maximize, and restore interactions where applicable.
- Fixed distorted or overflowing main-light and ambient-light switches.
- Matched ambient-colour swatches to their rounded-rectangle borders.

## Changed

- Added an interactive picker for custom ambient colours.
- Added snapped slider steps: 5% for main brightness, 20% for ambient
  brightness, and 100 K for colour temperature.
- Main colour temperature defaults to 3000–6400 K. An optional setting exposes
  the Yeelight-confirmed native 2700–6500 K range.
- Support is limited to exact `lamp15` / Yeelight Libra Pro / YLTD003 hardware.

The release remains unsigned, so Windows may display SmartScreen or
unknown-publisher warnings.
