# LibraTray v1.0.0

LibraTray v1.0.0 是面向 Yeelight Libra Pro（YLTD003）的首个稳定版本，采用托盘优先、
纯局域网的 Windows 控制方式。

[English release notes](https://github.com/hank-wang-cs/LibraTray/blob/v1.0.0/docs/releases/v1.0.0.md)

## 主要功能

- 分别控制主灯和氛围灯的电源与亮度。
- 主灯支持 3000–6500 K 色温。
- 支持氛围灯整灯 RGB 颜色和最多 20 个本地双通道预设。
- 协调应用命令、设备通知、状态查询与实体控制器产生的变化。
- 提供有界重试、请求节流、断线恢复，以及针对已观察到的固件 38 冷启动氛围灯问题的
  恢复流程。
- 可配置全局快捷键、托盘滚轮亮度调节和可选屏幕提示。
- 可选的 Windows 锁屏/显示器联动、当前用户开机自启及受保护的关机/开机状态恢复。
- 支持浅色、深色、跟随 Windows，以及简体中文和英文。
- 支持版本化本地配置导入/导出和脱敏诊断。
- 提供自包含 Windows x64 便携版 ZIP 和当前用户 MSI 安装包。

## 安装或更新

请从本 GitHub Release 选择官方文件：

- `LibraTray-1.0.0-win-x64.msi`：带向导的当前用户安装；
- `LibraTray-1.0.0-win-x64.zip`：自包含便携版；
- `SHA256SUMS.txt`：用于校验以上两个文件。

MSI 默认安装到 `%LOCALAPPDATA%\Programs\LibraTray`，也可以选择其他当前用户可写目录。
如已安装同为 1.0.0 的候选包，请先卸载候选包，再安装正式包。配置保存在当前 Windows
用户目录中。

## 系统要求

- Windows 10 21H2（内部版本 19044）或更高版本，或 Windows 11；
- x64 处理器；
- 电脑与灯具位于同一可信局域网；
- 如果厂商应用和固件提供局域网控制开关，需要先启用。

## 已知限制

- 文件没有代码签名。Windows 可能显示 SmartScreen 或未知发布者警告；运行前请核对
  SHA-256 清单。
- 只控制内部型号精确为 `lamp15` 的设备；本版本硬件验证主要基于 YLTD003 固件 38。
- 左右分区 RGB 有意保持关闭。即时硬件测试虽然成功，但它与之后出现的冷启动问题之间
  尚未完成安全的因果隔离。
- 固件 38 在独立关闭氛围灯时可能发送错误的背景灯电源通知，LibraTray 会通过状态查询
  进行校正。
- 已观察到固件 38 在冷断电后可能出现氛围灯渲染器沉默。需要恢复时，LibraTray 每个
  重连周期只执行一次有界情景刷新，并恢复之前确认的外观。
- LibraTray 使用 Yeelight 的明文本地协议，只应在可信专用网络上运行；协议本身不提供
  传输认证或加密。

## 验证情况

LibraTray 是独立开源项目，与 Yeelight 或小米没有隶属或官方认可关系。
